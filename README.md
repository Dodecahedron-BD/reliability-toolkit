# reliability-toolkit

Python tools for maintenance and reliability engineering analysis.

Built while preparing for SMRP CMRP certification, with each module
implementing methods from the SMRP Body of Knowledge.

## Scope

- **economics** — NPV, IRR, payback, equivalent annual cost, life cycle
  cost, cost of unreliability
- **metrics** — SMRP maintenance and reliability metrics
- **lifedata** — Weibull and exponential fitting from censored failure data
- **maintenance** — optimal PM interval from cost ratio and fitted life
  distribution
- **criticality** — FMECA scoring and asset criticality ranking
